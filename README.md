# My First Repository

## Data Analytics Assignment

This assignment focuses on analyzing a product dataset using Microsoft Excel.

### Tasks Performed

- Calculated the total, count, and average price of products.
- Found the minimum and maximum product prices.
- Used the IF function to categorize products into High Price and Standard Price.
- Used SUMIF and COUNTIF functions for product analysis.
- Used LEFT, RIGHT, and MID functions to extract information from Product ID.

### Tools Used

- Microsoft Excel
- GitHub

### ASSIGNMENT 2
1. **Handled Missing Price Values**

   * Checked the Price column for missing values.
   * Calculated the median price using the available prices.
   * Used the median value to fill the missing price values.

2. **Handled Missing Category Values**

   * Identified products with missing categories.
   * Assigned suitable categories based on the product name and type.

3. **Standardized Product Names**

   * Identified inconsistent capitalization in the Product Name column.
   * Changed names such as `laptop`, `smartphone`, and `headphones` to `Laptop`, `Smartphone`, and `Headphones`.

4. **Fixed Category Typos**

   * Found the typo `Electroni` in the Category column.
   * Replaced it with `Electronics` using Find and Replace.

5. **Removed Duplicate Rows**

   * Checked the entire dataset for duplicate rows.
   * Found and removed repeated rows using Excel's **Remove Duplicates** option.

6. **Split Product ID**

   * Split the Product ID into:

     * **Manufacturing Date**
     * **Country Code**
   * Removed the unnecessary separator characters from the new columns.

7. **Merged Product and Brand Names**

   * Combined the Brand Name and Product Name columns.
   * Created a new column named **Product Brand**.

8. **Formatted Price as Currency**

   * Changed the Price column to **US Dollar ($) currency format**.
   * Displayed prices with two decimal places.

9. **Formatted Manufacturing Date**

   * Formatted the Manufacturing Date column in **DD-MM-YYYY** format.
   * Added the year where required.

10. **Applied Conditional Formatting to Price**

    * Applied **Data Bars** to the Price column.
    * Higher prices are represented by longer bars.

11. **Highlighted Electronics Category**

    * Created a custom conditional formatting rule for the Category column.
    * Used the rule `=F2="Electronics"`.
    * Highlighted all cells containing **Electronics**.
